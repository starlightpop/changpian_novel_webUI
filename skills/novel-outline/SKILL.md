# novel-outline

## Purpose

Use this skill when the task is to create, audit, or revise a long-form novel outline.

## Steps

1. Extract hard constraints from background, synopsis, approved assets, audience, genre, CP, protagonist, and ending promise.
2. Build a four-stage outline: beginning, development, climax, ending.
3. Ensure each stage has cause, choice, consequence, emotional turn, and a visible hook.
4. Add suspense and reversals only when they are grounded in prior planting.
5. Audit the outline for logic, character agency, originality, emotional curve, and payoff.
6. If audit fails, revise the weakest stage rather than lowering standards.

## Output Expectations

- The outline must preserve user facts.
- The beginning must create immediate curiosity.
- The climax must be emotionally and logically earned.
- The ending must be surprising but inevitable.
