# character-system

## Purpose

Use this skill when the task is to build, audit, or repair a large cast and relationship topology.

## Steps

1. Start from canonical facts: protagonist, family, former sect, antagonists, neutral parties, civilians, hidden factions.
2. Generate a complete roster before writing detailed profiles.
3. Keep every character distinct in desire, goal, interest, agency, arc, highlight, and fate.
4. Protect core characters from being overwritten by antagonist or helper templates.
5. Build relationships from interests and conflicts, not only from labels.
6. Audit for duplicates, contradictions, missing factions, tool-like characters, and outline drift.
7. Repair only the named faulty characters and never copy another character's arc into them.

## Output Expectations

- At least the requested number of named characters.
- No placeholder names or group labels.
- Every important character must actively push plot.
- Relationship topology must expose alliances, debts, conflicts, and hidden links.
