# 网文背景设定语义分类

背景设定不是可直接拼接的素材词库，而是一组不同层级的创作约束。系统必须先分类，再结合简介编译成可执行规则。

推荐按以下结构输入一本书实际采用的标签：

`题材：「男频脑洞，都市日常」情节：「重生，鉴宝」角色：「赘婿，女总裁」情绪：「爽文，励志」背景：「现代，豪门世家」`

完整标签目录不能直接作为一本书的背景。系统会拒绝互斥受众、多个未解释的主世界、无 CP 与婚恋并存、后宫与纯爱并存，以及全局禁用题材。“架空”只表示制度或历史可虚构，不自动等于“架空古代”。

## 受众定位

男频、女频、大众向、男性向、女性向。

作用：决定核心欲望、反馈节奏、情绪兑现和关系篇幅。不得作为人物、势力、法宝或系统名称。

## 时代与世界

架空古代、历史架空、古代言情、现代言情、现代都市、古武都市、都市异能、东方玄幻、西方奇幻、修仙、仙侠、武侠、高武、低武、玄幻、奇幻、洪荒、神话、聊斋、志怪、末世、废土、悬疑、灵异、惊悚、推理、校园、职场、商战、娱乐圈、官场、军事、战争、谍战、历史、种田、科举、宅斗、宫斗、年代、民国、无限流、诸天流、游戏异界。

作用：约束社会制度、生产力、交通通讯、力量来源、职业体系、空间尺度和人物认知。

## 核心题材与故事形态

升级流、系统流、凡人流、宗门流、学院流、领主流、争霸流、幕后流、苟道流、无敌流、召唤流、御兽流、卡牌流、签到流、模拟器流、聊天群、快穿、穿书、重生、穿越、轮回、夺舍、变身、经营、基建、种田文、探案、破案、复仇、救赎、成长、群像、公路文、家族文、日常文。

作用：决定长期剧情发动机和阶段目标，不能只体现在名称上。

## 主角模型

强者崛起、废柴逆袭、天才流、草根崛起、幕后大佬、老爷爷流、赘婿、神豪、学霸、医生、律师、警察、侦探、反派主角、配角逆袭、大女主、女强、团宠、萌宝、奶爸、双强、全能。

作用：约束初始处境、核心欲望、能力边界、成长代价和命运方向。不得直接拼入实体名称。

## 世界内机制与金手指

系统、面板、签到、抽奖、加点、模拟器、空间、随身空间、金手指、血脉、传承、器灵、异能、御兽、召唤、卡牌、功德、气运、熟练度、复制、吞噬、合成、返还、选择奖励。

作用：必须说明来源、权限、触发条件、奖励边界、失败代价、成长方式和不可绕过的限制。

## 感情与关系模式

无 CP、单女主、单男主、多女主、后宫、纯爱、甜宠、虐恋、先婚后爱、破镜重圆、追妻火葬场、青梅竹马、欢喜冤家、双向暗恋、契约婚姻、带球跑、姐弟恋、年下、师徒恋、相爱相杀。

作用：约束主要关系数量、发展阶段、冲突来源和结局承诺。不得被当成势力或能力名称。

## 情绪与风格基调

热血、轻松、搞笑、幽默、治愈、温馨、甜、虐、暗黑、压抑、冷峻、史诗、悲壮、燃、沙雕、日常、现实、古典、唯美。

作用：控制场景表达和情绪曲线，不代表世界内存在同名力量。

## 读者体验承诺

爽文、高燃、高甜、高虐、快节奏、慢热、打脸、逆袭、复仇爽文、升级爽文、事业爽文、感情爽文、智斗、权谋、悬念、强者崛起、无敌、碾压、扮猪吃虎。

作用：必须落实为稳定的“压力、选择、行动、代价、兑现”循环。

## 叙事与创意策略

反套路、脑洞、创新、反转、多线叙事、群像多线、三幕多线、非线性叙事、多视角、单元剧、公路结构、悬疑推进、伏笔流、误导叙事、身份反转、认知反转、规则怪谈。

作用：控制信息释放和预期偏转。“反套路”必须有常见预期、前置铺垫、人物选择和因果后果，不得命名为“反套路天鉴”等实体。

## 创作质量约束

智商在线、逻辑严密、逻辑在线、人物立体、人物推动剧情、无降智、无毒点、不圣母、不后宫、不无脑、不水文、不拖沓、节奏紧凑、有因有果、伏笔回收、世界观统一、战力不崩、感情自然、文笔细腻。

作用：属于验收标准。必须由程序校验和审核 Agent 检查，不能成为故事内名词。

## 剧情结构

三幕式、英雄之旅、起承转合、单元剧、卷本结构、多卷长篇、百万字长篇、群像多线、双线叙事、多线叙事、时间线、因果链、伏笔闭环。

作用：决定事件卡、卷纲、叙事线、伏笔台账和状态台账的组织方式。

## 未知标签

词典外标签不得删除，也不得直接实体化。系统保留原词，结合简介、相邻标签和用户任务推断其类别；无法可靠判断时，将其标记为“待确认的创作约束”，不据此创造专有名词。
